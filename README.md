# 我们的共同计划

这是一个无云端、手机优先的情侣共同计划 PWA。它可以安装到手机主屏幕，像 App 一样独立打开；计划、文字回忆与照片默认只保存在当前设备。

## 打开

直接打开 `index.html` 可做桌面预览。要在手机上安装，需要通过 `https://` 或 `localhost` 访问；最简单的方式是在 `E:\清单` 目录启动静态服务器，再从手机访问电脑的局域网地址。

手机安装：

- Android Chrome：打开页面后选择“安装应用”或“添加到主屏幕”。
- iPhone Safari：点击分享按钮，选择“添加到主屏幕”。
- 安装完成后，从手机桌面图标打开，不再需要每次输入网址。
- 第一次安装需要网络访问页面；之后页面资源可以离线打开，数据仍保存在手机本地。

## 基本操作

- 通过“添加计划”新增一件想一起做的事。
- 点击卡片右上角编辑计划，完成标题、分类和备注的修改。
- 点击圆形按钮标记完成，完成后可写日期、文字和照片。
- 在“已经一起走过”区域编辑或删除回忆。
- 删除计划或回忆后会进入回收站，可随时恢复。

## 半同步

- “导出完整备份”会生成 JSON 文件，包含计划、状态、文字回忆和压缩照片。
- 在另一台设备选择“导入备份文件”，确认差异后合并。
- “生成轻量同步码”只包含计划、完成状态和文字，不包含照片；复制后发给另一台设备，再选择“导入轻量同步码”。
- 如果轻量同步码太长，请改用 JSON 文件。JSON 是可靠的完整备份方式。

## 隐私和限制

- 第一版没有云端数据库、账号、统计脚本或自动上传。
- 清除浏览器站点数据可能会清除本机内容，请定期导出 JSON 备份。
- 两台设备不会自动实时同步，需要手动导出/导入。
