# “我们的专属档案”彩蛋设计

## 意图

给情侣计划 App 增加一个隐藏的、只属于两个人的纪念档案页，让计划和回忆在积累后形成一份专属记录，而不是单纯的数据统计。

## 方案选择

- 关系系统自检：有趣，但更偏玩梗，容易像普通设备信息页。
- 未来来信：浪漫，但需要额外的日期解锁机制，和当前计划流程耦合较弱。
- 我们的专属档案：直接连接计划、进度和回忆，既有纪念意义，也最适合当前版本，因此采用此方案。

## 目标

- 隐藏入口，不占用首页主要操作区域。
- 展示共同空间创建日期、完成计划数、回忆数和最早完成的计划。
- 展示一条根据数据生成的专属文案。
- 在两台手机之间通过现有同步机制一起保留，不引入云数据库。

## 非目标

- 不复制储能柜铭牌项目的业务、字段或界面。
- 不新增账号、云端服务或付费存储。
- 不把档案做成可编辑的复杂资料页。

## 交互提案

入口放在首页进度区域的星星装饰上：连续点击星星 5 次后，出现轻微闪光和“发现了一份只属于你们的档案”，进入档案页。

档案页采用纪念卡片形式，包含：

- 标题：我们的专属档案
- 共同空间创建日期
- 已完成计划数量
- 已保存回忆数量
- 最早完成的计划及日期
- 一句动态文案，例如“你们已经一起完成了 N 件小事，故事还在继续。”
- 一个不影响功能的档案编号，用共同空间 ID 的短 hash 生成

如果数据不足，使用温和的空状态文案，不显示虚假的统计；例如没有完成计划时显示“第一件共同完成的事，正在等你们写下”。

## 解锁与同步

解锁状态仅保存在本机，不影响数据同步；档案内容始终从当前共同空间实时计算，因此另一台手机导入或合并数据后会自动得到相同内容。

## 验收标准

- 连续点击入口 5 次可以打开档案页，普通点击不会误触发。
- 档案统计与当前计划、回忆数据一致。
- 空数据状态文案正确。
- 导入或合并同步后，两台设备显示相同的档案信息。
- 不影响计划、回忆、照片保存和备份功能。
