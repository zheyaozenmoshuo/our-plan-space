# 回忆详情查看与图片取回设计

## 目标

让用户可以从回忆卡片进入独立的查看弹窗，浏览已经保存到 App 内的文字和照片；即使手机相册原图已经删除，也能在 App 内复制或下载保存的照片。

## 范围

- 回忆卡片支持点击查看，并增加明确的“查看回忆”入口。
- 详情弹窗展示日期、文字和多张照片，照片以大图/网格方式浏览。
- 每张照片支持复制到剪贴板和下载到设备；不支持时显示明确提示。
- 编辑、删除继续保留，但移动到详情弹窗的操作区，避免卡片只剩编辑和删除按钮。
- 不改变现有计划页的整体视觉风格，不引入云端存储。

## 方案

采用现有 HTML `dialog` 的回忆详情弹窗，不新增路由或页面状态。回忆数据已经把压缩后的图片保存为 Data URL，因此查看、复制和下载都直接使用 `memory.photos` 中的数据，不依赖手机相册文件。

## 交互约定

- 点击回忆卡片或“查看回忆”打开 `memoryViewModal`。
- 详情中显示回忆所属计划、日期、文字和照片数量。
- 无照片时显示空状态；有照片时首图突出显示，其余照片以缩略图排列。
- 点击照片可切换当前大图。
- “复制图片”优先使用 `navigator.clipboard.write`，不支持时给出提示；“下载图片”使用 Blob/Object URL 触发本地下载。
- 详情弹窗提供“编辑”“删除”“关闭”操作。

## 非目标

- 不把照片重新上传到云端。
- 不保证 iOS/Android 所有版本都支持系统剪贴板图片写入；不支持时只提示用户下载。

## 验收标准

1. 回忆卡片可以进入查看，不必先进入编辑。
2. 删除手机相册原图后，App 内仍能显示已保存照片。
3. 多张照片可以逐张浏览。
4. 下载后的图片可以在手机文件/相册中打开。
5. 复制功能在支持的环境成功提示，在不支持环境不报错、不丢失回忆数据。
6. 编辑、删除和取消查看不会误修改回忆。
